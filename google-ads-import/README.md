## 方法 A：Google Ads Editor（建議）

1. 下載安裝 [Google Ads Editor](https://ads.google.com/home/tools/ads-editor/)
2. 登入帳戶 `651-333-4793`
3. **帳戶 → 匯入 → 從 CSV…** 依序匯入：
   - `campaigns.csv`（先填 Daily budget 欄）
   - `keywords.csv`
   - `rsa-ads.csv`
   - `negative-keywords.csv`
   - `extensions.csv`（站內連結、附加說明）
4. 檢查預覽 → **發佈變更**

## 方法 B：Google Ads 網頁版大量上傳

1. Google Ads → **工具 → 大量上傳**
2. 上傳同一批 CSV（同樣要先填預算）
