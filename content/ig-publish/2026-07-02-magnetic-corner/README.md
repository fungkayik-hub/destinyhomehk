## 發 Reel 步驟
1. Instagram → + → Reel
2. 揀片源（Pictures 原版或 `public/videos/compass-magnetic-corner.mp4`）
3. 加字幕（import `hooks.srt` 或逐句打）
4. 封面：揀針轉嗰格 + 大字「支針轉不停 ⚠️」
5. 貼 `caption.txt` 內容
6. 分享去 Story（用 `story.txt`）
